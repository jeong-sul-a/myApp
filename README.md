# myApp

Android 앱 설치 파일을 모아 두는 저장소입니다.

## 성경·찬송가 앱 (MauiApp1)

성경 본문을 읽고 검색하며 찬송가를 찾아볼 수 있는 앱입니다. 성경 읽기 화면에서 번역본과 책, 장을 선택하고 글자 크기를 조절할 수 있습니다. 절을 선택해 복사하거나 최근 읽은 위치로 돌아갈 수 있으며, 검색 결과에서 원하는 구절로 바로 이동할 수 있습니다. 찬송가는 번호나 제목으로 찾아 가사를 보고, 기기에 저장된 찬송가 이미지를 연결해 볼 수 있습니다.

[성경·찬송가 앱 APK 다운로드](./성경찬송.apk)

## 근무·급여 계산 앱 (MauiApp2)

근무 일정을 달력에 기록하고 월별 근무 시간과 급여를 확인할 수 있는 앱입니다. 날짜별로 주간·오전·야간 근무 또는 휴무를 기록하며, 출퇴근 시각과 휴게 시간을 바탕으로 실제 근무 시간을 계산합니다. 근무 유형별 기본 시간과 시급 적용 이력을 설정할 수 있고, 설정한 야간 가산을 반영해 월별 급여를 계산합니다.

[근무·급여 계산 앱 APK 다운로드](./급여계산-Android.apk)

> 급여 결과는 앱에 입력한 근무 기록, 시급, 야간 가산 설정을 바탕으로 한 계산값입니다.
